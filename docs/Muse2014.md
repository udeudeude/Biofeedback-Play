# Muse 2014 / MU-01 integration

Biofeedback Play targets the user's first-generation InteraXon Muse, model MU-01.

## Transport

The MU-01 uses classic Bluetooth RFCOMM / Serial Port Profile rather than Bluetooth Low Energy. On macOS the current Biofeedback Play adapter uses a paired virtual serial port under `/dev/cu.*`.

The Device setup tab can scan macOS serial ports and lets the user select the Muse port. Pairing itself remains an operating-system action, so the app can open Bluetooth Settings when needed.

## Streaming protocol

The implementation uses preset `AD` and supports the packet forms documented/reimplemented by the open-source project:

- Matthew Piercey, **Muse 2014 LSL**: https://github.com/mtpiercey/muse-2014-lsl
- MIT licensed, clean-room implementation based on archived InteraXon protocol documentation.

The relevant stream contains:

- `E0` + 8 bytes: four-channel uncompressed EEG
- `A0` + 4 bytes: accelerometer
- `B0` + 8 bytes: battery
- `FF FF AA 55`: synchronization marker

The EEG channels are exposed as TP9, FP1, FP2, and TP10. Preset AD is treated as 500 Hz EEG and 50 Hz accelerometer based on the referenced implementation.

## Scaling cautions

The microvolt conversion uses the same AFE-gain-based approach described by the open-source clean-room implementation. Its author explicitly notes uncertainty around the exact scaling. Biofeedback Play therefore labels these values as experimental microvolts rather than calibrated EEG measurements.

Accelerometer channels are currently kept as signed raw 10-bit values instead of applying an uncertain physical-unit conversion.

## Commands

The adapter sends:

- `h` stop
- `v 2` protocol/version query
- `r 4` platform = Mac
- `% AD` research preset
- `?` status query
- `s` start streaming
- `k` keepalive every five seconds

If modern macOS does not expose an RFCOMM virtual serial port for this headband after pairing, a future native IOBluetooth bridge may be needed.
